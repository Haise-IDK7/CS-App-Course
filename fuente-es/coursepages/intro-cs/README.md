# Introducción a las ciencias de la computación y la programación con Python

Este curso te introducirá en el mundo de las ciencias de la computación y la programación, y te dará una idea del material que vendrá después. Si terminas el curso con ganas de más, ¡probablemente las ciencias de la computación son para ti!

Este curso lo ha desarrollado el MIT y está disponible en la plataforma [OCW del MIT](https://ocw.mit.edu) (OpenCourseWare).

> Introduction to Computer Science and Programming in Python está dirigido a estudiantes con poca o ninguna experiencia en programación. Su objetivo es que los estudiantes comprendan el papel que puede desempeñar la computación en la resolución de problemas y ayudarles, sea cual sea su carrera, a sentirse con razón seguros de su capacidad para escribir programas pequeños que les permitan lograr objetivos útiles. La asignatura usa el lenguaje de programación Python.

**Enlace al curso:** <https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/material-by-lecture/>

## Instrucciones

1. Abre el [enlace al curso](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/material-by-lecture/) indicado arriba. Verás una lista de clases.
2. Al hacer clic en el enlace de una clase, verás todos los materiales de esa clase.
3. Avanza por todas las clases del curso tal como aparecen en el enlace de arriba. Mira los videos, haz los ejercicios breves de práctica (*finger exercises*) y después resuelve los conjuntos de problemas.
4. No se espera que completes los conjuntos de problemas en cuanto aparecen en la página de una clase. Se espera que empieces a pensar en ellos a partir de ese momento. Las fechas de entrega reales, según el [calendario del curso](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/calendar/), son:

   - PSET 0: antes de la clase 1
   - PSET 1: antes de la clase 9
   - PSET 2: antes de la clase 12
   - PSET 3: antes de la clase 16
   - PSET 4: antes de la clase 20
   - PSET 5: antes de la clase 25

6. En la página de cada clase hay enlaces a las soluciones de los ejercicios breves. Compara tus respuestas con esas soluciones para autoevaluarte.
7. Cada conjunto de problemas incluye un script e instrucciones para comprobar tu solución. Úsalos para autoevaluarte.
8. No necesitas instalar la distribución completa de Anaconda para hacer este curso. Consulta la sección de notas, más abajo, para más información.
9. Si te atascas, no dudes en preguntar. Puedes unirte al chat de OSSU para este curso aquí: <https://discord.gg/jvchSm9>.

## Notas

**Por problemas de compatibilidad, recomendamos usar Python 3.8.X. Puedes usar una herramienta como pyenv, uv o conda para fijar una versión anterior de Python. La última versión de Spyder no es compatible con Python 3.8, así que se recomienda la versión 6.0.8 (enlazada más abajo).**

1. El curso recomienda [Anaconda](https://www.anaconda.com/docs/getting-started/anaconda/install/overview), que instala el IDE Spyder y herramientas para gestionar entornos virtuales con los que puedes fijar tu versión de Python. Como alternativa, puedes descargar el IDE Spyder desde [aquí](https://github.com/spyder-ide/spyder/releases?q=6.0.8&expanded=true), que instala los paquetes necesarios para este curso sin ocupar lo que ocupa la distribución completa de Anaconda. Ten en cuenta que aun así tendrás que hacer algo de trabajo para que funcione la versión correcta de Python.
2. Puedes usar VS Code o cualquier editor de texto o IDE que prefieras. Si usas un editor o IDE distinto de Spyder/Anaconda, ten en cuenta que a veces el curso te pide ejecutar algunas sentencias adicionales después de ejecutar un archivo de Python. Para hacerlo, ejecuta `python -i file.py`. Así podrás ejecutar sentencias adicionales. 
3. No recibirás ningún certificado por hacer este curso. Si de verdad quieres un certificado, tienes que hacer en edX el [curso 6.00.1x](https://www.edx.org/course/introduction-to-computer-science-and-programming-7), más rápido y con el ritmo marcado por el profesor. El certificado de un curso introductorio como este no es muy valioso, así que, salvo que lo tengas muy claro, te recomendamos hacer en su lugar el curso 6.100L enlazado arriba.
4. Si por algún motivo quieres hacer la versión de OCW del curso 6.0001, de ritmo más rápido, puedes hacerlo aquí: <https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/>.
5. El curso indica como lectura obligatoria el libro de texto [Introduction to Computation and Programming Using Python, third edition](https://mitpress.mit.edu/9780262542364/introduction-to-computation-and-programming-using-python/). Como con cualquier curso de OSSU, recuerda: todo complemento de pago debe considerarse opcional. No reprobarás este curso si no lees el libro. «El libro y las clases del curso van en paralelo, aunque el libro da más detalle sobre algunos temas». No te pierdes tanto como para que importe.
